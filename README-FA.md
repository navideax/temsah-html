# TEMSAH V30 — نسخه HTML ایستا با محتوای واقعی در فایل‌های HTML

این نسخه بر مبنای HTML مرجع V29 استخراج شده است. **تمام متن‌ها، محصولات نمونه، مقالات، کارت‌ها، هدر، فوتر و محتوای پنل‌ها داخل خود فایل‌های HTML قرار دارند.** فایل‌های app.js و medals.js حذف شده‌اند. `interactions.js` فقط تعاملات نمایشی را اجرا می‌کند و لیست محصول یا محتوا درون آن تعریف نشده است.

## باز کردن
فایل `index.html` را باز کنید. در صورت محدودیت مرورگر برای localStorage روی مسیر file://، با یک سرور استاتیک مثل `python -m http.server 8000` اجرا کنید.

- `product-1.html` تا `product-12.html`: جزئیات هر محصول به صورت HTML مستقل.
- `article-1.html` تا `article-4.html`: مقالات مستقل.
- `seller-1.html` تا `seller-4.html`: پروفایل فروشندگان مستقل.
- `cart.html`: قالب‌های HTML سبد برای هر ۱۲ محصول داخل همان فایل نوشته شده‌اند؛ JavaScript فقط آیتم‌های انتخاب‌شده در مرورگر را نشان می‌دهد.
- فایل‌های `product.html`، `article.html` و `seller.html` نیز برای سازگاری مسیرهای قدیمی باقی مانده‌اند.

## محدودیت‌های ذاتی نسخه HTML
محصولات، امتیازها، تعداد فروش و اطلاعات داخل پنل **محتوای نمونه مرجع V29** هستند که اکنون در HTML ذخیره شده‌اند؛ داده واقعی فروشگاه نیستند. ورود، عضویت، پرداخت بانکی، ثبت سفارش و ارسال پیام/تیکت بدون سرور و دیتابیس امکان عملکرد واقعی ندارند. فرم‌های مربوطه نمایشی‌اند. داده‌های تعاملی سبد فقط در مرورگر همان کاربر نگهداری می‌شوند. **هیچ JavaScriptی هنگام بارگذاری صفحه محتوای اصلی را از یک آرایه نمی‌سازد.**

## اصول
- CSS، تصاویر و Iconly نسخه V29 حفظ شده‌اند.
- نسبت مربع تصاویر کارت‌ها، چیدمان گالری و تب‌های محصول حفظ شده‌اند.
- هیچ سرویسی برای دانلود داده یا نمایش محصول از شبکه فراخوانی نمی‌شود.
- برای ویرایش نام، قیمت و محتوای هر محصول، همان فایل HTML مربوطه را تغییر دهید. نمونه نمایش محصول در صفحه اصلی و سایر آرشیوها مستقل است و برای هماهنگی باید در همان HTMLها نیز اصلاح شود.
