# محدودیت‌ها و پیش‌نیازهای استقرار عملیاتی (Known Limitations)

پیش از انتشار سایت روی دامنه اصلی به موارد زیر توجه کنید:

1. **ورود با رمز یک‌بارمصرف پیامکی (SMS OTP)**:
   - در فرم ورود، یادآور اتصال پنل پیامکی نمایش داده می‌شود. هسته امن وردپرس (`user_login` + `user_pass` + بازیابی ایمیل) کاملاً فعال و آزمایش‌شده است؛ اتصال به سامانه پیامکی (کاوهنگار، ملی‌پیامک و...) مستلزم ثبت کلید API سرویس پیامکی شما از طریق هوک/افزونه مکمّل است.
2. **اطلاعات پذیرنده درگاه بانکی واقعی (زرین‌پال / سامان)**:
   - درگاه **سندباکس آزمایشی (HMAC)** بدون نیاز به حساب بانکی آماده تست است. برای تراکنش ریالی واقعی باید Merchant ID زرین‌پال یا ترمینال سامان خود را در `تمساح -> تنظیمات` وارد کنید.
3. **قانون Nginx برای مخزن دانلود (`wp-content/temsah-vault/`)**:
   - فایل `.htaccess` به‌صورت خودکار برای وب‌سرورهای Apache / LiteSpeed ایجاد می‌شود. روی سرورهای Nginx حتماً بلاک `location ~* ^/wp-content/temsah-vault/ { deny all; return 403; }` را در کانفیگ سرور اعمال کنید (در `01-INSTALLATION.md` توضیح داده شده است).
4. **ارسال ایمیل تراکنش و بازیابی رمز**:
   - برای اطمینان از رسیدن ایمیل‌های فراموشی رمز، فاکتور و اعلان‌ها در سرور واقعی، پیکربندی یک سرویس/افزونه SMTP معتبر در وردپرس توصیه می‌شود.
5. **محیط آزمایش خودکار**:
   - آزمون‌های خودکار داخل محیط PHP 8.5.12 WASM + SQLite (`WordPress 6.7.2` + `sqlite-database-integration`) اجرا شده‌اند؛ تمام دستورات دیتابیس بر پایه استاندارد `$wpdb` و `dbDelta()` برای سازگاری کامل با MySQL/MariaDB نیز نوشته شده‌اند.
