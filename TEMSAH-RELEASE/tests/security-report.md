# گزارش ممیزی امنیتی تمساح (Security Audit Report)

تمامی کنترل‌های امنیتی در سطح افزونه `temsah-core`، قالب `temsah-theme` و لایه REST API تحت شرایط واقعی تست نفوذ خودکار (`e2e-suite.mjs`) تایید شدند:

| بردار حمله / کنترل امنیتی | آزمون اجراشده | نتیجه |
|---|---|---|
| **دسترسی مهمان به صفحات خصوصی** | درخواست GET به `checkout`, `account`, `account/downloads`, `vendor`, `vendor/withdrawals` بدون نشست | **مسدود (`302` به ورود + `Cache-Control: no-store` + `X-Robots-Tag: noindex, nofollow`)** |
| **دسترسی مهمان به REST خصوصی** | درخواست GET به `/temsah/v1/account/orders` و `/temsah/v1/vendor/stats` بدون نشست | **مسدود (`401 Unauthorized`)** |
| **جعل درخواست بین‌سایتی (CSRF) در REST** | درخواست POST به `/temsah/v1/cart/add` بدون هدر `X-WP-Nonce` | **مسدود (`403 rest_forbidden_nonce`)** |
| **ارتقای غیرمجاز سطح دسترسی (Privilege Escalation)** | تلاش خریدار و همچنین فروشنده در وضعیت `pending` برای باز کردن `/vendor` یا `/temsah/v1/vendor/stats` | **مسدود (`403 Forbidden`)** |
| **IDOR روی سفارش‌ها و فاکتورها** | تلاش کاربر `sara` برای مشاهده `account/order-detail&id={ali_order}` | **مسدود (`403 Forbidden`)** |
| **IDOR روی ویرایش محصولات فروشنده دیگر** | تلاش فروشنده `sara` برای باز کردن `vendor/edit-product&id=1` | **مسدود (`403 Forbidden`)** |
| **دستکاری امضای پرداخت (Payment Tampering)** | ارسال `sig=tampered` در Callback درگاه Sandbox | **رد شده؛ سفارش پرداخت‌نشده باقی ماند** |
| **حمله تکرار پرداخت (Replay Attack)** | فراخوانی مجدد `process_callback` روی یک `authority` از قبل پرداخت‌شده | **مسدود (`already_paid: true`)؛ کمیسیون و لایسنس تکراری صادر نشد** |
| **محافظت از مخزن دانلود (`temsah-vault`)** | وجود `.htaccess` و `index.php`؛ دانلود مستقیم لینک با Nonce کاربر `ali` توسط کاربر دیگر `sara` | **دانلود مجاز: ۲۰۰ با استریم ZIP / کاربر دیگر: ۴۰۳ مسدود** |
| **تزریق XSS ذخیره‌شده** | ارسال پرسش محصول حاوی `<script>alert(1)</script><img src=x onerror=alert(1)>` | **تگ اسکریپت در ورودی پاک‌سازی و خروجی کاملاً Escape شد** |
| **تزریق فرمول در خروجی CSV** | بررسی خروجی `stream_vendor_csv()` روی نام محصولات و هدرهای HTTP | **خنثی‌سازی کاراکترهای `= + - @ \t \r` و افزودن `nosniff`** |
| **ثبت نظر جعلی بدون خرید** | تلاش کاربر غیرخریدار برای ثبت دیدگاه ستاره‌دار (`kind=review`) | **مسدود؛ فقط خریداران تاییدشده مجاز به ثبت نظر خریدار هستند** |
| **خرید تکراری محصول تملک‌شده** | افزودن مجدد محصول خریداری‌شده به سبد خرید | **مسدود و اطلاع‌رسانی به کاربر برای دانلود از پنل** |

---

## نتیجه‌گیری ممیزی
در جریان تست کامل، **هیچ آسیب‌پذیری بحرانی یا متوسط (Critical / High / Medium)** بدون پوشانده‌شدن باقی نماند و تمامی لاگ‌های امنیتی در جدول `wp_temsah_activity_logs` ثبت می‌شوند.
