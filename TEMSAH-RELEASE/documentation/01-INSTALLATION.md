# راهنمای نصب و راه‌اندازی تمساح (TEMSAH)

این بسته شامل دو افزونه و قالب مستقل و استاندارد وردپرس است:
- **`temsah-core.zip`**: افزونه هسته تجاری مارکت‌پلیس چندفروشندگی (دیتابیس اختصاصی، نقش‌ها، سبد خرید، درگاه پرداخت، کمیسیون، لایسنس، مخزن امن دانلود، تیکت و REST API)
- **`temsah-theme.zip`**: قالب گرافیکی راست‌به‌چپ (RTL) کاملاً منطبق با نسخه نهایی رابط کاربری V31

---

## ۱. پیش‌نیازهای سرور
- **WordPress**: نسخه `6.4` یا بالاتر (آزمایش‌شده روی `6.7.2`)
- **PHP**: نسخه `8.1` تا `8.5` (آزمایش‌شده با `PHP 8.5.12`) به همراه افزونه‌های `json`, `mbstring`, `fileinfo`, `openssl`, `curl`
- **دیتابیس**: `MySQL 8.0+` یا `MariaDB 10.4+` (یا `SQLite` از طریق `sqlite-database-integration`)
- **SSL/HTTPS**: در محیط عملیاتی استفاده از گواهی معتبر SSL برای امنیت نشست‌ها و درگاه پرداخت الزامی است.

---

## ۲. مراحل نصب (گام‌به‌گام)
1. **نصب افزونه هسته**:
   - وارد پیشخوان وردپرس شوید: `افزونه‌ها -> افزودن -> بارگذاری افزونه`
   - فایل `temsah-core.zip` را انتخاب و نصب کنید، سپس **فعال‌سازی (Activate)** را بزنید.
   - هنگام فعال‌سازی به‌صورت خودکار ۲۶ جدول اختصاصی `wp_temsah_*` ساخته شده و نقش‌های کاربری و پوشه امن `wp-content/temsah-vault/` ایجاد می‌شوند.
2. **نصب قالب**:
   - به مسیر `نمایش -> پوسته‌ها -> افزودن -> بارگذاری پوسته` بروید.
   - فایل `temsah-theme.zip` را بارگذاری و **فعال** کنید.
3. **تنظیم پیوندهای یکتا (Permalinks)**:
   - به `تنظیمات -> پیوندهای یکتا` بروید و ساختار را روی **نام نوشته (`/%postname%/`)** بگذارید و دکمه **ذخیره تغییرات** را بزنید تا قوانین مسیریابی (`/shop/`, `/account/`, `/vendor/`, `/seller/{slug}/`) فعال شوند.
   - نکته: حتی در سرورهایی که `mod_rewrite` غیرفعال باشد، سیستم به‌صورت خودکار از fallback پارامتر `?temsah_route=...` پشتیبانی می‌کند.

---

## ۳. محافظت از مخزن فایل‌ها (Vault Protection)
پوشه ذخیره‌سازی فایل محصولات در مسیر `wp-content/temsah-vault/` ساخته می‌شود و به‌صورت خودکار حاوی `.htaccess` (`Deny from all` / `Require all denied`) و `index.php` است.

### در وب‌سرور **Nginx** (الزامی)
در فایل کانفیگ Nginx سایت خود بلوک زیر را پیش از `location /` اضافه کنید تا دسترسی مستقیم HTTP به فایل‌های فشرده مخزن کاملاً مسدود شود:

```nginx
location ~* ^/wp-content/temsah-vault/ {
    deny all;
    return 403;
}
```

---

## ۴. پیکربندی اولیه مدیر کل
پس از فعال‌سازی، منوی **«تمساح»** در پیشخوان وردپرس ظاهر می‌شود:
- **تنظیمات کلی و درگاه‌ها**: درصد کمیسیون پلتفرم (پیش‌فرض ۳۰٪)، حداقل مبلغ برداشت (پیش‌فرض ۲۰۰,۰۰۰ تومان)، انتخاب درگاه فعال (`زرین‌پال`، `سامان`، یا `سندباکس آزمایشی`) و کلید درگاه.
- **تنظیمات قالب**: مدیریت شعار هیرو، متن نوار اعلان، اسلایدها و لینک‌های فوتر.
- **ابزارها (داده‌های آزمایشی)**: برای تست یا نمایش اولیه می‌توانید از دکمه نصب داده‌های آزمایشی استفاده کرده و پیش از انتشار عمومی با یک کلیک داده‌های آزمایشی را کاملاً پاک‌سازی کنید.
